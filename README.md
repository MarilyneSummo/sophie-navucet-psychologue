# Site de Sophie NAVUCET

Site internet professionnel de **Sophie NAVUCET**, psychologue spécialisée en neuropsychologie et psychothérapeute TCC(E).

## Comment modifier le contenu

Le site est conçu pour être très simple à mettre à jour. **Tout le texte se trouve dans un seul fichier : `content.md`.**

### Modifier un texte

1. Va sur la page du fichier `content.md` dans ce dépôt GitHub.
2. Clique sur le petit crayon ✏️ en haut à droite du fichier.
3. Modifie le texte entre les titres.
4. Quand tu as fini, fais défiler tout en bas et clique sur **Commit changes** (valider les modifications).
5. Le site se met à jour automatiquement en environ 1 minute.

### Structure du fichier

Le fichier utilise une syntaxe très simple :

```markdown
# Titre principal de section

Texte de la section...

## Sous-section

Texte de la sous-section...

- élément de liste
- autre élément

**texte en gras**

[titre du lien](https://adresse-du-site.fr)
```

- `#` = section principale (Accueil, Présentation, Activités, etc.)
- `##` = sous-section
- `###` = carte / encadré dans une section
- `- ` = liste à puces
- `**texte**` = gras
- `[texte](lien)` = lien cliquable

### Faire attention

- Ne change pas la ligne `# Sophie NAVUCET` au tout début.
- Ne change pas les titres commençant par `#` ou `##` si tu veux garder la même structure.
- Si tu veux ajouter une nouvelle carte dans "Activités" ou "Outils", crée un nouveau bloc commençant par `###`.

### Modifier une image

Les images se trouvent dans le dossier `assets/images/`.

Pour remplacer une image, upload un nouveau fichier avec **exactement le même nom** que l’ancien.

Par exemple, pour changer le portrait de la page d’accueil, remplace `assets/images/portrait-about.jpg` par une nouvelle photo du même nom.
